# RO 放置仙境攻略規劃

整理 [RO 放置仙境資訊站](https://ro-idle.app/info)所對應遊戲的攻略：角色培養、裝備與物品取捨、掛機設定與練功地圖。目標是讓玩家依自己的角色狀態與遊玩目標做選擇，而不是只給一個「最佳解」。

## 網站閱讀

閱讀網站：[RO 放置仙境攻略索引](https://ned-lin-9527.github.io/Ragnarok/)。網站從 `Role/` 與 `裝備/` 的 Markdown 自動產生職業目錄、裝備分析、全文搜尋與文章章節導覽。建置與部署方式見 [site/README.md](site/README.md)。原始 Markdown 仍是攻略的內容來源。

網站另有[技能配點模擬器](https://ned-lin-9527.github.io/Ragnarok/skills.html)：涵蓋初學者、超級初心者、一轉與二轉共 21 個職業（進階二轉尚未開放，暫不收錄），依資訊站的技能樹、前置與點數規則計算，可記錄學習順序、複製成攻略的技能配點表或分享連結。

## 閱讀前須知

- **版本定位**：此遊戲的設計接近《仙境傳說》R 版前（Pre-Renewal）。攻略常以 R 版前的配點、技能路線、配裝與練功地圖作為起點，但本遊戲可能調整公式、數值、掉落或掛機機制，兩者不一致時以本遊戲資料與實測為準。
- **標示方式**：攻略會區分「已查證的遊戲資料」、「玩家實測」、「依資料計算的結果」與「建議／待驗證假設」。尚未在本遊戲確認的 R 版前內容標為「R 版前參考／待此遊戲驗證」。
- **時效**：每份攻略開頭有「最後查證」日期。遊戲更新後數值、掉率與限制可能改變，使用前請對照資訊站。
- **掉率**：資訊站所列為基準掉率，不等於角色實際掉率；活動倍率與其他修正需另外確認。

## 每份角色攻略的結構

角色攻略依相同章節順序撰寫，方便橫向比較。初心者攻略只涵蓋一轉前；一轉後的屬性、技能與配裝須選定職業才能確定，攻略會明記待補，不預設數值。

1. **目的與適用條件**：結論、適用對象、前提與缺少的玩家資料。
2. **流派定位與選擇**：該職業各流派的比較，主推流派以粗體標示。
3. **轉職路線與階段定義**：轉職條件、技能點與各階段要點。
4. **① 轉職前屬性配點、② 轉職前技能配點、③ 轉職後屬性配點、④ 轉職後技能配點**：依 Base／Job 等級列出累計目標值、投入順序與理由。
5. **配裝建議**：轉職前／後的過渡與目標裝備、替代品、取得方式。
6. **掛機設定與練功地圖**：掛機規則、候選地圖，以及可重現的測試方法與判斷門檻。
7. **比較與取捨**、**風險與待確認事項**、**依據與資料來源**。

完整範本與撰寫規則見 [AGENTS.md](AGENTS.md)。

## 專案結構

```text
Role/<一轉職業>/<二轉職業>/     角色培養攻略
Role/初心者/、Role/超級初心者/  不分一轉、二轉的職業
技能/                            各職業技能說明與放置版限制
裝備/                            跨職業的裝備保留與賣出分析
data/                            資訊站資料快照，檔名附查詢日期
tools/                           產生分析檔的腳本
site/                            攻略閱讀網站原始碼與已產生的 dist/
.github/workflows/pages.yml      GitHub Pages 自動建置與部署
AGENTS.md                        撰寫規則、資料查證原則與攻略範本
```

## 新增與更新培養攻略

完成 `Role/` 的攻略後，同步更新本頁「角色培養」索引與尚未撰寫清單，執行 `node site/build.cjs` 重新產生網站，並確認首頁、文章頁及搜尋索引。詳細檢查項目見 [AGENTS.md](AGENTS.md#培養攻略的同步更新流程)；公開站的部署方式見 [site/README.md](site/README.md)。

## 重新產生裝備逐件判定

[`裝備/裝備逐件保留判定.md`](裝備/裝備逐件保留判定.md) 由腳本根據 `data/` 中的資訊站快照產生，請勿手動修改。更新判定規則或快照後執行（需要 Python 3，無外部套件）：

```bash
python3 tools/產生裝備逐件判定.py
```

快照檔路徑寫在腳本的 `SNAPSHOT` 常數；換新快照時一併更新。

## 重新擷取技能樹資料

技能配點模擬器讀取 `data/` 中日期最新的 `ro-idle技能樹資料_YYYY-MM-DD.json`。遊戲更新技能後，先開啟資訊站確認目前載入的 `index-*.js`，下載後執行（需要 Node.js）：

```bash
node tools/擷取技能樹資料.cjs <下載的 bundle.js> <查詢日期 YYYY-MM-DD>
```

接著執行 `python3 tools/產生職業技能說明.py` 與 `node site/build.cjs`，同步更新各職業技能說明、`data/ro-idle技能重點_YYYY-MM-DD.json`、模擬器與閱讀網站。人工整理的放置版重點維護於產生腳本，修改後也須重新執行這兩步。

## 資料來源

1. [RO 放置仙境資訊站](https://ro-idle.app/info)：職業、技能、怪物、道具、地圖等資料頁，攻略引用時附名稱、ID 與直達連結。
2. 遊戲內畫面、戰鬥紀錄與玩家實測：記錄角色、裝備、地圖、測試時長與日期。
3. R 版前《仙境傳說》資料與玩家攻略：作為候選方案與查找線索，逐項標明版本與驗證狀態。

## 參與與回報

發現攻略數值與遊戲實際不符時，請附上：資訊站頁面或遊戲畫面、角色條件（職業、等級、素質、裝備）、測試地圖與時長、觀測日期。差異會保留雙方來源並標記待驗證，再更新攻略。

新增或修改攻略前，請先閱讀 [AGENTS.md](AGENTS.md) 的章節範本與查證規則。

## 免責聲明

本專案為玩家自行整理的非官方攻略，與遊戲營運方及資訊站無隸屬關係。遊戲名稱、道具名稱等專有名詞版權屬原權利人所有。
